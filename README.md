# BRICK 🧱

Классическая головоломка с падающими фигурами в стиле карманной консоли — один React-компонент, без внешних ассетов.

## Возможности

- **Движок**: 7-bag рандомизатор (на каждый экземпляр игры свой), wall kicks при повороте, ghost-подсветка посадки, lock-out (game over при запирании фигуры над полем)
- **Прогресс**: уровень = каждые 10 линий; классическая таблица очков Nintendo (40/100/300/1200 × уровень)
- **Гравитация**: интервал 800 мс → 90 мс, −60 мс за уровень
- **Управление**: клавиатура (стрелки, X/↑ — поворот, Space — hard drop, P — пауза, M — звук), экранные кнопки с **работающим press-and-hold (DAS)**, свайпы (включается в OPTIONS)
- **Настройки**: звук, вибрация, quick-down, жесты, цвет корпуса — всё сохраняется в localStorage
- **Доступность**: `role="dialog"` + фокус-трап в OPTIONS, `role="switch"` у тумблеров, `aria-pressed` у свотчей, aria-label на всех кнопках

## Структура

```
src/
  game/logic.js   — чистый движок (без React/DOM): коллизии, повороты,
                    линии, счёт, уровни, гравитация, ghost-drop
  BrickGame.jsx   — UI-компонент консоли
  main.jsx        — точка входа
  styles.css      — глобальный сброс
```

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm test          # юнит-тесты движка и UI (Vitest + Testing Library)
npm run lint      # ESLint
npm run build     # production-сборка в dist/
```

## Управление

| Клавиша     | Действие          |
| ----------- | ----------------- |
| ← / →       | движение          |
| ↓           | мягкое падение    |
| ↑ / X       | поворот           |
| Space       | мгновенный сброс  |
| P           | пауза             |
| M           | звук вкл/выкл     |
| Enter/Space | старт после конца |
| Esc         | закрыть OPTIONS   |
